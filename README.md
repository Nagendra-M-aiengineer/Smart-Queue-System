# Manipal Hospitals Smart Queue System

A modern, responsive real-time queue management web application for Manipal Hospitals.

## Features

- **📱 Patient App (Queue Tracker)**:
  - Live token number tracking
  - Number of patients ahead
  - Estimated waiting time
  - Progress indicator
  - Upcoming appointment details with urgency tags

- **💻 Doctor Dashboard**:
  - Today's appointment schedule
  - Real-time queue overview (current token, next token, waiting count)
  - Next Patient progression controls

## Quick Start

Open `index.html` directly in your browser or with VS Code Live Server.

## Tech Stack

- HTML5
- Tailwind CSS (via CDN)
- React 18 & ReactDOM
- Babel Standalone
